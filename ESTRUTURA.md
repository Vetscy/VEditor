# Estrutura do Projeto V - Edições e Designs

## 📄 Páginas

### 1. **home.html** - Página Principal 🏠
- **Cor**: Roxo (Purple theme)
- **Objetivo**: Página inicial com apresentação da marca V
- **Seções**:
  - Hero Section com boas-vindas
  - Cards explicando os dois serviços (Vídeos + Designs)
  - CTA buttons para ambas as seções
  - Seção de contato

### 2. **portfolio.html** - Portfólio de Vídeos 🎬
- **Cor**: Vermelho/Pink (Red theme)
- **Objetivo**: Portfólio de edição de vídeos
- **Seções**:
  - Demonstração de vídeo do Google Drive
  - Serviços oferecidos (Shorts, YouTube, Twitch)
  - Informações de contato

### 3. **comissoes.html** - Comissões de Modelos 🎨
- **Cor**: Rosa/Magenta (Pink theme)
- **Objetivo**: Serviço de design de personagens
- **Seções**:
  - Portfólio de trabalhos
  - Tipos de comissões disponíveis
  - Processo de trabalho
  - Informações de contato

## 📁 Arquivos CSS

- **home-style.css** - Estilos da página principal (roxo)
- **style.css** - Estilos do portfólio de vídeos (vermelho/pink)
- **comissoes-style.css** - Estilos da página de comissões (rosa/magenta)

## 📱 Scripts

- **home-script.js** - Funcionalidades da página home
- **script.js** - Funcionalidades do portfólio de vídeos
- **comissoes-script.js** - Funcionalidades da página de comissões

## 🚀 Como Usar

1. Abra **home.html** como página inicial
2. Os botões na home levam para as outras páginas
3. Cada página tem um botão "Voltar" na navegação superior
